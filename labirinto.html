Labirinto dos Algoritmos

Explore, responda e abra caminho para uma tecnologia mais justa.

Fase: 1/3
Pontos: 0
Desafios: 0/5

Setas ou WASD para andar. Segure a tecla para continuar andando.

Como jogar

  • Encontre os cinco símbolos ? espalhados pelo mapa.
  • Responda às perguntas para coletar cada desafio.
  • Cada resposta errada tira 50 pontos; a pontuação nunca fica abaixo de zero.
  • Quando todos forem resolvidos, a saída será liberada.
  • São três fases com labirintos e perguntas sorteados.
